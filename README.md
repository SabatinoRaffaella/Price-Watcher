# Price-Watcher
🔧 Price-Watcher main job is checking prices of product that a user adds to its own watchlist. <br>
💰 It aims to update user on price discount when available or check for lowest prices. <br>  
📫 It also aims to keep in touch with the user by notifying him using an internal mailbox system, <br> 
📧 as a way to avoid cluttering an e-mail mailbox with notifications.
